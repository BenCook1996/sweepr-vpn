1. Install kmod-wireguard & Configure LuCI Interface

SSH into your router (or open System → Software inside LuCI) to pull kernel modules and web UI support, then reload the network service before opening the Interfaces tab: 

opkg update
opkg install kmod-wireguard wireguard-tools luci-proto-wireguard
# Optional selective policy routing package:
opkg install pbr luci-app-pbr
service rpcd restart && service network reload
  1. In LuCI open Network → Interfaces → Add new interface, name it wg0, pick Protocol WireGuard VPN, and paste your SWEEPR PrivateKey plus tunnel IP (10.64.0.2/32).
  2. Under the Peers tab, click Add peer (or use Import configuration in OpenWrt 23.05+), enter the server PublicKey, Endpoint host/port 51820, Allowed IPs: 0.0.0.0/0, and Persistent Keep Alive: 25.
  3. Check Route Allowed IPs for whole-home encryption, or leave it unchecked when letting pbr drive per-device rules.

2. WAN/VPN Firewall Zone Masquerading, MSS Clamping & PBR

Create a firewall zone named vpn covering interface wg0 with Masquerading and MSS clamping (option mtu_fix '1') turned on. Point lan => vpn forwarding toward your new zone. For strict kill-switch protection, remove wan from lan destination forwarding so LAN hosts cannot leak cleartext packets if wg0 resets.

OpenWrt 23.05 WireGuard FAQ

Why disable Route Allowed IPs when using OpenWrt pbr?

Leaving Route Allowed IPs checked overrides OpenWrt's default gateway for every LAN device. With pbr managing custom routing tables, unchecking it lets you keep selective hosts on wan.

Does OpenWrt Software Flow Offloading work with WireGuard?

Software offloading speeds up unencrypted WAN forwarding, while WireGuard packets bypass flowtables cleanly. On multi-core Filogic or Rockchip boards, enabling Packet Steering improves throughput more noticeably.

Why do HTTPS pages stall on OpenWrt over BT or Sky PPPoE?

Enable MSS clamping (mtu_fix) on the vpn firewall zone and drop wg0 interface MTU to 1412 so PPPoE overhead never clips TCP handshakes.
