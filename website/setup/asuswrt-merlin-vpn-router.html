1. Broadcom Runner vs. Flow Cache Acceleration on Merlin

Legacy OpenVPN on ASUS Broadcom routers saturates a single Cortex-A53/A7 core around 65–190 Mbps because packet crypto runs solely in user space. 2. Configuring WireGuard Client (wgc1) & VPN Director Rules

  1. Open VPN → WireGuard Client, select slot Client 1 (wgc1), and click Import .conf file using your exported SWEEPR London or Amsterdam keypair.
  2. Toggle Inbound Firewall to Block, set Enable NAT to Yes, and leave Internet Connection configured for selective routing if only certain devices should traverse the tunnel.
  3. Open LAN → DHCP Server and assign static DHCP reservations (for instance 192.168.50.110 for your Apple TV and 192.168.50.111 for a bedroom Smart TV) so their local IPs never drift.
  4. Switch to VPN → VPN Director and add explicit policy rows routing your media/gaming range through WGC1 while pinning your Synology NAS and work laptop to WAN.

ASUSWRT-Merlin WireGuard Troubleshooting FAQ

In what order does VPN Director evaluate WAN vs. WGC1 rules?

Merlin processes all explicit WAN bypass entries before WGC1–WGC5 rules. You can safely route an entire subnet like 192.168.50.0/24 to WGC1 while punching out specific /32 IPs to WAN.

Do wired or wireless AiMesh nodes honor VPN Director tunnels?

Yes. AiMesh satellites act as Layer-2 access bridges back to the primary Merlin router, so any client IP matched by VPN Director receives encrypted routing seamlessly across mesh rooms.

Why does Hardware Acceleration show Flow Cache enabled but Runner disabled?

Broadcom's packet Runner engine cannot encapsulate WireGuard headers in silicon, so Merlin cleanly hands wgc1 packets to the kernel while keeping Flow Cache active for LAN switching and WAN rules.
