2. Stopping Smart Multi-Homed Name Resolution (SMHNR) & IPv6 Leaks

Windows 10 and 11 ship with Smart Multi-Homed Name Resolution (SMHNR), which blasts simultaneous DNS queries out every connected adapter—Ethernet, Wi-Fi, and Hyper-V bridges—and accepts whichever reply arrives fastest. Without strict Windows Filtering Platform (WFP) firewall filters blocking non-tunnel UDP port 53 and external IPv6 egress, your ISP resolver still sees domains you visit.

Windows 10 & 11 WireGuardNT FAQ

Why does ipconfig /all still list my Ethernet ISP DNS alongside the tunnel?

Windows displays per-adapter DHCP settings even while WFP blocks non-tunnel DNS traffic. Verify real outbound resolution using our browser leak tool or Resolve-DnsName rather than static ipconfig output.

Does WireGuardNT support Windows 11 on ARM64 Snapdragon laptops?

Yes—native ARM64 kernel drivers exist for Windows 11 Copilot+ PCs, delivering wire-speed encryption without x64 Prism emulation overhead.

How does WFP kill-switch behavior differ from user-space firewall toggles?

WFP registers persistent kernel-level permit/block filters before packets reach the NIC, stopping bursts during sleep/wake Wi-Fi reconnects where user-space apps react several seconds too late.
