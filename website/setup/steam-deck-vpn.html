Verifying .nmconnection Permissions & Autoconnect on SteamOS

If NetworkManager ignores an imported profile on boot, check that the generated unit under /etc/NetworkManager/system-connections/ carries 0600 root ownership and set connection.autoconnect yes solely if you want the Deck tunneling automatically on every Wi-Fi network.

sudo chmod 600 /etc/NetworkManager/system-connections/sweepr-lon01.nmconnection
nmcli connection modify sweepr-lon01 connection.autoconnect no
