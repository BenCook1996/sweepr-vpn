# UX Copy

## Principles

1. **Verb over noun**, "Send order" > "Order submission"
2. **Specific over generic**, "Save as draft" > "Save"
3. **Human over robotic**, "Maintain account" > "Manage account"
4. **Error helps, doesn't blame**, "We don't recognize this email yet" > "Invalid email"

## Output

3 variants per request:
- **Safe** (conservative, clear)
- **Direct** (short, lively)
- **Style break** (bolder, with the brand's own tone)

For each: a one-sentence rationale + risk note.
