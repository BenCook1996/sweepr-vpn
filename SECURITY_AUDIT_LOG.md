# SWEEPR VPN (`sweeprvpn.com`) — Daily White-Hat Security Audit & Auto-Remediation Log

## 2026-10-21 — Initial Baseline Audit & Hardening Pass
- **Finding 1 (Internal SEO/CRM State File Disclosure)**: `website/outreach-seed.json`, `website/indexing-queue.json`, and `website/daily-seo-pages-state.json` were located inside the static web root (`website/`) where `.json` is an allowed static extension.
  - **Remediation Implemented**: Added `outreach-seed.json`, `indexing-queue.json`, and `daily-seo-pages-state.json` to `BLOCKED_STATIC_FILES` in `website/server.mjs` so direct HTTP requests return `403 Forbidden`.
- **Finding 2 (Sandboxed Iframe `Origin: null` in Trusted Origin Allowlist)**: `resolveTrustedOrigin(req)` in `website/server.mjs` included `'null'` in `allowedOrigins`, which could allow sandboxed `<iframe>` or `data:` URI contexts to pass origin validation.
  - **Remediation Implemented**: Removed `'null'` from `allowedOrigins` while retaining explicit Tauri origins (`tauri://localhost`, `http://tauri.localhost`, `https://tauri.localhost`).
- **Finding 3 (HSTS Preload & Cross-Origin Opener Isolation)**: `COMMON_SECURITY_HEADERS` in `website/server.mjs` lacked `Strict-Transport-Security` and `Cross-Origin-Opener-Policy`.
  - **Remediation Implemented**: Added `Strict-Transport-Security: max-age=31536000; includeSubDomains; preload` and `Cross-Origin-Opener-Policy: same-origin-allow-popups` to `COMMON_SECURITY_HEADERS`.

## 2026-10-21 — End-to-End Red-Team Anti-Fraud & Licensing Hardening Pass (12 Vulnerabilities Patched)
- **Vuln 1 (Unconditional Demo Pro Backdoor `849201` / `demo@sweeprvpn.com`)**: Disabled unconditional demo seeding in `website/server.mjs` and purged/blocked `demo@sweeprvpn.com` / `849201` / `SWEEPR-VPN-PRO1-2026-DEMO` in `sweepr_crm` unless `ALLOW_DEMO_ACCOUNT=true` in non-production. Updated `desktop-client/SweeprVpnApp.cs` self-test and rebuilt `SweeprVpnApp.exe` and `website/SWEEPRVPN.exe`.
- **Vuln 2 (`account_id` Leakage on `/api/vpn/leads` & `/v1/license/verify-key`)**: Stripped `account_id` and `activation_code` from unauthenticated responses and masked email addresses (`c***6@gmail.com`).
- **Vuln 3 (Unauthenticated Token Refresh on `/v1/license/refresh`)**: Required valid `refresh_token` (or `Authorization: Bearer`) bound to `account_id` and `device_id` on `/v1/license/refresh` in both `website/server.mjs` and `sweepr_crm/src/app.ts`.
- **Vuln 4 (6-Digit Activation Code Brute-Forcing & Collision Prevention)**: Added `generateUniqueSixDigitKey()` collision check in `sweepr_crm/src/db.ts` and required matching account `email` whenever a 6-digit activation code is used on `/api/vpn/activate`, `/api/vpn/verify-key`, `/v1/license/activate`, `/v1/license/verify-key`, and `/api/vpn/wg-config`.
- **Vuln 5 (Chargeback/Refund WireGuard Peer Revocation + 72h Peer Lease TTL)**: Added `revokeLicenceOnAllNodes()` and `POST /api/vpn/revoke` in `website/server.mjs`, wired automatic revocation notifications from `sweepr_crm` on subscription cancellation/refund/device revocation, and enforced a 72-hour peer lease TTL (`PEER_TTL_SECONDS = 72 * 3600`) with background reaping in `infra/node/sweepr_agent.py`.
- **Vuln 6 (Referral Bonus Self-Dealing)**: Updated `applyReferral` in `sweepr_crm/src/db.ts` to verify the referred account has an active paid Stripe subscription or paid invoice before granting +30 days.
- **Vuln 7 (Hardcoded `sweepr_crm_shared_secret_v1` Fallback)**: Removed hardcoded fallback secret in `website/server.mjs`, `website/sweepr-client.mjs`, and `.env.example`, rotated `.env` to a 256-bit secret, and explicitly rejected `sweepr_crm_shared_secret_v1` in `sweepr_crm/src/app.ts`.
- **Vuln 8 (Unsigned Stripe Webhooks & Replay Protection)**: Enforced mandatory `STRIPE_WEBHOOK_SECRET` HMAC verification (`verifyStripeWebhookSignature`) and `processedStripeWebhookEvents` replay deduplication in `website/server.mjs`.
- **Vuln 9 (Localhost Licensing Spoofing & Offline Ed25519 Signature Verification)**: Restricted `default_api_candidates()` in `crates/sweepr-tunnel/src/lib.rs` to `https://sweeprvpn.com` in release builds, added offline `ed25519-dalek` signature verification (`verify_ed25519_license_token`) in Rust, and added WebCrypto Ed25519 verification (`verifySignedLicenseToken`) across `desktop-client/app-ui.html`, `apps/desktop-tauri/ui/index.html`, and `website/app-preview.html`.
- **Vuln 10 (£1.99 Intro Offer Abuse via `+tag` Aliases & Card Fingerprints)**: Canonicalized email addresses (`canonicalizeEmailForAntiAbuse`) and tracked `claimedIntroEmails`, `claimedIntroCustomerIds`, and Stripe card `fingerprint` (`claimedIntroCardFingerprints`) in `website/server.mjs`.
- **Vuln 11 (Spoofable Geo-Pricing Headers)**: Ignored client-supplied `x-country-code` and only trusted `cf-ipcountry` / `x-vercel-ip-country` when `TRUST_PROXY` is enabled.
- **Vuln 12 (Disabled Tauri WebView CSP)**: Configured strict Content Security Policy in `apps/desktop-tauri/src-tauri/tauri.conf.json`.
